PACOM Station 将建筑中的空间、设备、配置与运行资料组织在一起。业主与运营人员可从日常任务进入；集成商可沿项目规划、现场部署、验证交付的流程查阅。

## 系统组成

| 组成 | 主要职责 |
| --- | --- |
| PACOM Station | 组织项目空间、设备规划和应用配置；汇集部署记录，衔接验证交付、运行、告警与分析。 |
| 部署 App | 承接现场识别、绑定、配置与测试，同步实际记录和现场变更。 |
| 边缘网关 | 衔接现场设备网络与平台，按型号与固件能力采集数据、同步配置或转发执行。 |
| 传感器、控制器与终端 | 采集现场信息，或执行相应控制与本地功能。 |

本地控制由具体设备与现场规则决定。平台或网络暂不可用时，远程状态可能未知；现场功能是否继续运行，应按对应设备与已下发配置核对。

## 应用与典型场景

以办公建筑为例，可以从四类任务理解平台：

- **照明**：查看空间的开关、亮度、照度与占用状态，理解自动策略和手动操作的关系。
- **暖通空调**：查看温度、模式与设定，核对可读、可控对象及原厂保护条件。
- **室内环境**：查看有效环境指标和趋势，识别缺测、异常与需要现场核查的情况。
- **能源**：明确计量与分项范围，分析用能变化，并按实际数据和方法理解碳排放。

跨应用场景需要相应传感来源、控制对象和接口能力。选型与设计时，将希望完成的场景写成可验证的目标。

## 开始使用

1. **确认访问**：新机构由申请人提出，经 PACOM 审核开通；已有机构成员按邀请加入。
2. **确认范围**：核对当前机构、项目及个人权限，避免在错误对象上操作。
3. **选择路线**：项目建设从[项目与设备](/platform/projects-devices)开始；现场实施查阅[配置与交付](/platform/configuration-delivery)；已交付项目进入[日常运营](/platform/operations)。

## 关键概念与状态

**项目与空间**说明管理范围和设备服务的位置；**点位与设备**分别表达规划位置和现场实体。**网络**组织设备通信；**照明回路**对应控制器及其负载，**回路组**组织共同控制；**自定义分组**用于管理对象。

| 状态 | 应核对的依据 |
| --- | --- |
| 已保存、已批准 | 规划资料已保存，或配置获得执行许可。 |
| 已绑定、已应用 | 实际设备身份和配置回执。 |
| 在线 | 有效的连接与状态记录，连同更新时间。 |
| 已验证、已交付 | 测试证据、网络范围、配置版本和交付记录。 |

批准不等于设备已应用；在线不等于功能已验证。具体能力以所用平台版本、设备型号和已完成的接入验证为准。
