在 **PACOM Station**（PACOM 智能建筑平台的 Web 工作区）中查看日常运行和控制结果。运营人员、配置人员与机构管理员使用总览；获授权的空间使用者从**我的区域**进入。

<Note>
从已交付、已接入运行数据的范围开始。提示**尚未取得运行数据**或**执行服务尚未接入**时，规划、草稿和演示结果不能作为现场状态或执行依据。
</Note>

## 查看运行

<Steps>
  <Step title="选择范围">

    打开**总览**，确认机构并选择项目、楼宇或楼层。楼层查看状态图；楼宇及以上查看下一级对比表，统计只包含已接入运行数据的楼层。

    普通成员从**我的区域**打开获授权的功能区，查看照明、空调与室内环境，并按权限控制照明和空调；不使用总览五页签、能源、场景、告警或大屏。查看人员只能查看。

  </Step>
  <Step title="先看需要处理的事项">

    在**概况**查看未恢复告警、设备在线率、今日用电和环境正常的空间，再检查**需要处理**。点击功能区查看详情；告警从对应条目或图上角标进入[告警](/platform/alarms)。

    核对**数据截至**、覆盖范围与数据质量。总览、告警、场景有运行数据时每分钟更新；超过 5 分钟未取得新数据会提示重试，变暗的旧数值不能当作当前值。

  </Step>
  <Step title="确认对象后操作">

    有控制权限时，从功能区或单台设备进入操作。整层或多对象控制前，核对实际设备、服务功能区、动作、离线情况和有效时间，再确认下发。

    普通成员只能控制服务功能区全部在授权内的设备；跨功能区回路组须覆盖全部相关区域。权限与授权问题见[机构设置](/platform/organization)。

  </Step>
  <Step title="核对回读与记录">

    提交、受理与生效分别核对，以设备实际回报为准。平台控制查看总览的**操作记录**；场景、定时与联动查看**场景 › 执行记录**。批量操作逐对象或逐网络核对。

    同一次确认包含空调和照明时，先下发空调；两类动作分别核对回执，不能用其中一类成功代替整体结果。

  </Step>
</Steps>

### 判断结果

| 看到的状态 | 下一步 |
| --- | --- |
| **所选范围没有运行数据** | 核对接入范围，切换到已接入的楼层；缺数不等于零值或正常。 |
| **网关离线 / 状态未知** | 先检查网关与通信；不能据此把所有下级设备都判为离线。 |
| 单台控制**未确认** | 下发后 5 秒未取得确认时，先核对原请求与实际状态。需要重试时重新确认当前条件，不自动重复下发。 |
| 组控制**未回报 N 台** | 约 45 秒仍未回报时用**重新查询**。未回报不等于未执行，不能直接当作失败重试。 |
| **已生效 N/M / 部分成功** | 定位剩余对象及原因；已生效对象不重复下发，确认失败的对象重新核对范围与权限后按需重试。 |

没有传感器时，占用或环境读数为未知，不显示为 0。**有人 / 无人**表示占用状态，不表示人数。

## 大屏

从**总览 › 大屏**打开当前范围的只读画面。项目或全部项目打开管理版式，楼宇或楼层打开值班版式；长期展示可用展示链接选择相应版式。

| 版式 | 适合展示 |
| --- | --- |
| **值班** | 一个或几个楼层的状态图、未恢复告警、设备在线率、用电与环境。 |
| **管理** | 项目或全部项目的用电、碳排放、能耗强度、在线率、告警及下一级比较。 |
| **公共** | 楼宇或楼层的环境与能源概况，可选横屏或竖屏；隐藏告警、设备与占用。 |

临时查看使用登录后的大屏，沿用本人授权与会话超时。长期展示须所用版本已接入展示服务，由机构管理员在**机构设置 › 展示链接**新建，核对名称、版式、范围，再**复制链接**到屏上打开。普通成员不使用大屏。

大屏只读，触控仅用于浏览楼层、功能区或下一级比较；控制设备和确认告警回到对应运营页面。公开展示前核对可见范围；修改或撤销链接后检查已打开屏幕的实际结果。大屏同样要看更新时间与数据质量，不能把展示正常当作运行无异常。

展示链接管理见[机构设置](/platform/organization)，历史评估与报告进入[数据分析](/platform/analytics)。
