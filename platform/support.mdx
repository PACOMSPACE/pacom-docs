需要帮助时，先找到具体对象，再核对数据与操作记录。以下搜索和帮助入口均指 **PACOM Station 工作区**；本网站的文档搜索用于查阅操作说明。

机构管理员、配置人员、运营人员和查看人员可打开**搜索或提问**；普通成员没有搜索入口，可直接阅读[常见问题](#常见问题)和[联系支持](#联系支持)。AI 提问与建议流程见[智能助手](/platform/assistant)。

## 搜索

点击侧栏**搜索**，或按 **⌘K**（其他系统 **Ctrl+K**）打开**搜索或提问**。手机先打开菜单再点**搜索**；面板中切换**搜索 / 提问**，按 **Esc** 或点击面板外关闭。

<Steps>
  <Step title="输入名称或设备标识">

    在**搜索**页签输入对象名称、UUID 或序列号。结果按项目、楼宇、楼层、功能区、设备、设备网络和场景分组；有运行数据时，也列出未恢复告警。

    空输入时显示固定的**快捷入口**，不是最近使用历史。查设备时，先用点位名称定位，需要核对实物再用序列号。

  </Step>
  <Step title="核对位置再打开">

    核对结果所附的项目与位置，避免进入另一个同名对象。点击结果打开；搜索时按回车会打开第一条结果。

    功能区有运行数据时，可用**查看运行**看当前状态，用**编辑空间**进入配置资料；楼层也可进入空间资料。查看人员使用**查看空间资料**等只读入口。

  </Step>
  <Step title="找不到时核对范围">

    先核对当前机构、本人项目授权、名称和设备标识，再从[项目管理](/platform/projects)定位。成员与权限问题见[机构设置](/platform/organization#角色与权限)。

    对象不存在、已删除或无访问权限可能使用相同提示，不能仅凭搜索无结果或旧链接失效认定对象已删除；不自动跳到同名对象。

  </Step>
</Steps>

想直接定位时，使用明确的对象名称或标识；以“为什么”“多少”等开头的输入可能被识别为问题。转为提问后的依据核对、建议确认和服务状态，见[智能助手](/platform/assistant)。

## 常见问题

先按症状找到检查入口，保留原操作记录和未保存内容。

| 症状 | 优先核对 |
| --- | --- |
| 无法加入或查看机构 | 受邀邮箱、邀请状态、当前机构和最新授权；见[机构设置](/platform/organization)。 |
| 图纸与现场不一致 | 楼层、图纸版本、比例尺、点位与设备身份；见[项目管理](/platform/projects)。 |
| 设备离线或数据缺失 | 最后更新时间、来源、网关联网与设备网络；见[设备管理](/platform/devices)。 |
| 控制结果未知 | 原请求、实际回读与现场状态，避免重复下发；见[运行总览](/platform/runtime)。 |
| 配置未生效 | 当前期望配置版本、同步状态与设备应用回执；保存或批准不等于已应用，见[部署调试](/platform/deployment)。 |
| 报告或导出不可用 | 数据、文件类别、服务状态、角色与范围；见[数据分析](/platform/analytics)及[导出权限](/platform/organization#数据导出与删除)。 |
| **网络连接已中断** | 当前页面保留未保存修改，恢复网络后再保存；不要把离线保存提示当成成功。 |
| **无法加载 PACOM Station** | 检查浏览器是否允许站点读取与保存数据，再重新加载；必要时展开**技术信息**。不要直接清除站点数据，以免丢失本地规划。 |

设备专项问题查阅对应产品资料；接口与联调问题进入[开发文档](/developers/troubleshooting)。无法定位时，按下方流程准备支持材料。

## 帮助

从左下角**机构菜单 › 帮助**打开帮助弹窗。

- **软件版本**：读取实际使用的软件版本与日期，反馈问题时保留；文档或固件版本不能代替软件版本。
- **更新说明**：按版本从新到旧查看变化，当前版本有标记；先核对说明涉及的页面，再检查自己的使用情况。
- **查看术语**：按拼音查看常用名词、定义和出现页面，辨明规划、配置、回执等含义。
- **使用指南**：当前应用内仍显示**正式文档准备中**。可从本网站侧栏按任务查阅平台、指南与设备文档。

查设备或准备报修时，按任务选择标识，不必搜集全部编号：

| 标识 | 用途 |
| --- | --- |
| **点位名称** | 日常定位空间中的设备与规划点位。 |
| **序列号** | 核对现场实物、报修或更换设备。 |
| **UUID** | 部署 App 读取的硬件身份，用于绑定核对。 |
| **内部标识** | 联系技术支持时定位平台记录，按需要提供。 |

“设备复位”是现场恢复出厂，“电表复位”是电表读数归零，二者操作和影响不同。对术语有疑问时，先查看它出现的页面再处理。

## 联系支持

<Note>
  当前支持服务尚未接入，页面不能直接提交或上传截图。请先复制内容，再通过邮件发送；已复制不代表已发送或受理。
</Note>

已登录时打开**机构菜单 › 帮助 › 联系支持**；无法登录时，可在账户页面的**联系我们**取得同一支持邮箱。

<Steps>
  <Step title="写清问题">

    在**问题说明**写明：哪个页面、针对什么对象、做了什么、看到了什么，以及预期结果。补充发生时间、影响范围、可复现步骤和已做的检查。

    软件版本会列入复制内容。设备或部署问题再按需补充型号、序列号、固件版本、当前配置版本及相关回执；这些资料不会自动收集。

  </Step>
  <Step title="选择并检查附带内容">

    **当前对象、日志、截图**均为可选，默认不附带，只选择解决问题所需的内容。请勿填写或发送密码、短信验证码、令牌与密钥；检查文字、图片和附件，移除电子邮箱、手机号码、网址路径及无关个人或客户资料。

    页面不会自动截图，也不保证截图自动脱敏。请在选择和发送前自行检查。

  </Step>
  <Step title="复制后发送邮件">

    点击**复制内容**，将文本粘贴到发给 [support@pacom.cn](mailto:support@pacom.cn) 的邮件中；选择的截图须另外作为邮件附件添加。

    **已复制**仅表示内容已复制，不代表已发送或受理；浏览器无法自动复制时，按提示选中下方全文手动复制。发送后保留邮件往来和支持回复，便于跟进。

  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="附带内容具体包含什么" description="先预览再决定，页面日志与设备日志分别准备。">

    - **当前对象**：当前机构与角色、页面名称和页面地址；不是自动导出整个项目。
    - **日志**：本次打开页面以来最近最多 20 条提示与错误，时间按中国标准时间记录；可展开**查看将附带的日志**逐条核对，没有日志时不可选。这是页面内存记录，不是设备日志或完整服务端审计。
    - **截图**：点击 **选择截图…**，选取 PNG 或 JPG 图片，核对文件名与大小；不合适时可**移除**，或点击 **更换截图…** 重新选择。图片需另附在邮件中，选择文件不等于上传。

  </Accordion>
</AccordionGroup>
