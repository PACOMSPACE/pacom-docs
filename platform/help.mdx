需要帮助时，先确认版本、对象与发生时间。使用智能助手或提交反馈时，仅提供解决问题所需的资料。

## 智能助手

按所用版本提供的功能选择对象与上下文，查看回答的数据来源和更新时间。分析建议与配置草稿需要人工核对；控制、批准与执行仍遵守原有权限和确认流程。

没有有效数据依据的回答，不应直接作为现场操作或验收结论。资料涉及个人信息、客户记录或凭据时，先移除无关内容。

## 常见问题

| 症状 | 优先核对 |
| --- | --- |
| 无法加入或查看机构 | 账户、邀请状态、机构及最新授权范围。 |
| 图纸与现场不一致 | 楼层、图纸版本、比例尺、规划点位与实际设备身份。 |
| 设备离线或数据缺失 | 最后更新时间、数据来源、网关联网与设备网络。 |
| 控制结果未知 | 原请求记录、实际回读与现场状态，避免重复提交。 |
| 配置未生效 | 批准版本、部署记录与设备应用回执。 |
| 报告或导出不可用 | 当前版本、有效数据、文件类别、角色与授权范围。 |

## 联系支持

按实际平台提供的支持渠道反馈，并准备：

- 平台、设备与固件版本。
- 发生时间、影响范围和预期结果。
- 可复现步骤、实际状态、必要截图或日志。
- 已做的检查与处理。

移除密码、令牌、密钥及无关个人信息。记录正式渠道返回的受理信息，便于后续跟进。设备问题同时查阅对应产品资料；接口与联调问题进入[开发文档](/developers/troubleshooting)。
