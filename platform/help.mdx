需要帮助时，先找到具体对象，再核对数据与操作记录。搜索用于定位，AI 用于理解与建议；操作结果仍以实际服务、设备回执和现场状态为准。

机构管理员、配置人员、运营人员和查看人员可使用搜索与提问。普通成员没有搜索或 AI 入口，可直接阅读[常见问题](#常见问题)和[联系支持](#联系支持)。

## 搜索与定位

点击侧栏**搜索**，或按 **⌘K**（其他系统 **Ctrl+K**）打开**搜索或提问**。手机先打开菜单再点**搜索**；面板中切换**搜索 / 提问**，按 **Esc** 或点击面板外关闭。

<Steps>
  <Step title="输入名称或设备标识">
    在**搜索**页签输入对象名称、UUID 或序列号。结果按项目、楼宇、楼层、功能区、设备、设备网络和场景分组；有运行数据时，也列出未恢复告警。

    空输入时显示固定的**快捷入口**，不是最近使用历史。查设备时，先用点位名称定位，需要核对实物再用序列号。
  </Step>
  <Step title="核对位置再打开">
    核对结果所附的项目与位置，避免进入另一个同名对象。点击结果打开；搜索时按回车会打开第一条结果。

    功能区有运行数据时，可用**查看运行**看当前状态，用**编辑空间**进入配置资料；楼层也可进入空间资料。查看人员使用**查看空间资料**等只读入口。
  </Step>
  <Step title="找不到时核对范围">
    先核对当前机构、本人项目授权、名称和设备标识，再从[项目与设备](/platform/projects-devices)定位。成员与权限问题见[机构与账户](/platform/organization-account#成员与权限)。

    对象不存在、已删除或无访问权限可能使用相同提示，不能仅凭搜索无结果或旧链接失效认定对象已删除；不自动跳到同名对象。
  </Step>
</Steps>

输入问题时，可点击**提问 AI**或按 **Shift+Enter**转为提问；以“为什么”“多少”等开头的输入也可能自动按问题处理。想直接定位时，使用明确的对象名称或标识。

## 智能助手

<Note>
  当前正式版尚未接入运行数据与 AI 问答服务，只能搜索；演示回答由页面规则和示例数据生成。以下说明数据与服务可用时的问答、依据核对和建议流程，演示结果不能作为现场操作或验收结论。
</Note>

### 提问与追问

在**搜索或提问 › 提问**中输入一个明确问题，包含**位置、对象或指标、时间范围**，再按回车。可询问用电、碳排放、电费、告警、设备状态、空气质量、占用与灯光等项目数据。

先问一件事，再围绕回答追问。范围不明确时补充楼宇、楼层或功能区名称；比较变化时写清期间、指标和单位，不只问“是不是正常”或“有没有节能”。

<AccordionGroup>
  <Accordion title="可以这样问" description="用实际位置替换示例名称，并先确认相应数据已接入。">
    - 办公楼 3F 现在有哪些离线设备？
    - 办公楼 3F 昨天用了多少电？
    - 办公楼 3F 近 7 天有没有夜间照明偏高的告警？
    - 会议室现在的 CO₂ 和 PM2.5 情况怎样？
    - 办公楼 3F 本月用电折合多少碳排放，依据是什么？

    示例用于说明问题写法，不保证当前版本能回答任意期间或范围。可先使用提问页签中的**可以这样问**，再用**追问**补充细节；AI 卡片上的**追问**也会打开提问面板。
  </Accordion>
</AccordionGroup>

### 核对回答与依据

回答包含**AI 生成**标记、范围、正文、**依据**和追问建议。先核对它回答的是哪个位置、哪段时间，再阅读结论。

- **范围**：有**回答范围**按钮时，可在当前楼层全层与功能区间选择，同一问题按新范围重新回答；追问后也要重新核对范围。
- **依据**：逐项打开对应对象或页面，检查数据时间、单位、来源、质量与计量边界。未注明时间或依据不足时，回到原页面核查。
- **数值**：区分事实、**推断、估算**与建议；未分区计量时，功能区用电只能按说明理解估算，缺数也不能当作零。
- **参数**：电费须有适用电价与用户类别，碳排放须有覆盖期间的因子与设置版本；缺少条件时保留未计算或待设置，不自行补值。

用电、碳排放和环境口径见[分析与报告](/platform/analysis-reports)。AI 只能使用本人有授权的项目资料；正式回答、依据与权限过滤须由服务核对，不能凭演示回答判断真实数据或访问权限。

### 确认建议与结果

AI 卡片可出现在**今日要点、异常解释、告警根因分析、报告草稿**中。展开**依据 N 项**核查来源；查看人员可读回答与依据，没有建议操作按钮。

有权限的人员点击建议后，在**确认 AI 建议**中逐项核对**将要做什么、影响对象、预计效果、预估依据、如何回退**及注意事项，再按建议类型确认。

| 确认按钮 | 实际含义 |
| --- | --- |
| **保存为配置草稿** | 保存规划，不下发、不改变设备。用**在配置参数中查看**核对或放弃；形成有效版本仍须相应批准流程。 |
| **确认并写入工单** | 追加排查步骤并记录采纳人；不代替派工、现场处理或故障恢复。 |
| **确认下发** | 在同一确认中核对对象、动作、范围、离线与影响等控制内容；一次确认即下发，执行者为本人。随后核对回执与实际状态。 |
| **我已知晓** | 记录提醒，不改变配置或设备。 |

当前示例配置草稿的配置项尚未纳入参数模板，**确认并形成新版本**不可用；保存草稿不能视为已批准或已生效。配置与交付见[配置与交付](/platform/configuration-delivery)，控制回执见[日常运营](/platform/operations)，工单处理见[告警与维护](/platform/alarms-maintenance#工单与排查)。

AI 不改变成员授权、硬件兼容与安全保护。需要定时或反复执行时，由有权限的人员另行确认保存场景或时间表；每项建议仍受本人权限和实际服务能力约束。

### 回答不可用时

| 提示或情况 | 下一步 |
| --- | --- |
| **尚未取得运行数据** | 继续搜索对象；先核对项目接入和数据来源，不用规划或演示数据替代运行回答。 |
| 问题超出可回答范围 | 缩小位置、期间与指标，回到对应业务页查看；数据没有覆盖时不能推导完整结论。 |
| **AI 暂时无法回答** | **重试**沿用同一问题与范围；**改用搜索**保留输入，仍有问题用**帮助**联系支持。 |
| **订阅后可用**或 AI 用量已用完 | 搜索照常可用；联系机构管理员核对订阅、重置日期或用量包。 |

搜索、AI 卡片与没有得到回答的提问不计入 AI 提问用量；用量与订阅以正式服务为准，见[机构与账户](/platform/organization-account#许可、用量与数据)。

## 常见问题

先按症状找到检查入口，保留原操作记录和未保存内容。

| 症状 | 优先核对 |
| --- | --- |
| 无法加入或查看机构 | 受邀邮箱、邀请状态、当前机构和最新授权；见[机构与账户](/platform/organization-account)。 |
| 图纸与现场不一致 | 楼层、图纸版本、比例尺、点位与设备身份；见[项目与设备](/platform/projects-devices)。 |
| 设备离线或数据缺失 | 最后更新时间、来源、网关联网与设备网络；见[告警与维护](/platform/alarms-maintenance)。 |
| 控制结果未知 | 原请求、实际回读与现场状态，避免重复下发；见[日常运营](/platform/operations)。 |
| 配置未生效 | 当前期望配置版本、同步状态与设备应用回执；保存或批准不等于已应用，见[配置与交付](/platform/configuration-delivery)。 |
| 报告或导出不可用 | 数据、文件类别、服务状态、角色与范围；见[分析与报告](/platform/analysis-reports)及[导出权限](/platform/organization-account#数据导出与注销)。 |
| **网络连接已中断** | 当前页面保留未保存修改，恢复网络后再保存；不要把离线保存提示当成成功。 |
| **无法加载 PACOM Station** | 检查浏览器是否允许站点读取与保存数据，再重新加载；必要时展开**技术信息**。不要直接清除站点数据，以免丢失本地规划。 |

设备专项问题查阅对应产品资料；接口与联调问题进入[开发文档](/developers/troubleshooting)。无法定位时，按下方流程准备支持材料。

## 版本与术语

从左下角**机构菜单 › 帮助**打开帮助弹窗。

- **软件版本**：读取实际使用的软件版本与日期，反馈问题时保留；文档或固件版本不能代替软件版本。
- **更新说明**：按版本从新到旧查看变化，当前版本有标记；先核对说明涉及的页面，再检查自己的使用情况。
- **查看术语**：按拼音查看常用名词、定义和出现页面，辨明规划、配置、回执等含义。
- **使用指南**：当前应用内仍显示**正式文档准备中**。可从本网站侧栏按任务查阅平台、指南与设备文档。

查设备或准备报修时，按任务选择标识，不必搜集全部编号：

| 标识 | 用途 |
| --- | --- |
| **点位名称** | 日常定位空间中的设备与规划点位。 |
| **序列号** | 核对现场实物、报修或更换设备。 |
| **UUID** | 部署 App 读取的硬件身份，用于绑定核对。 |
| **内部标识** | 联系技术支持时定位平台记录，按需要提供。 |

“设备复位”是现场恢复出厂，“电表复位”是电表读数归零，二者操作和影响不同。对术语有疑问时，先查看它出现的页面再处理。

## 联系支持

已登录时打开**机构菜单 › 帮助 › 联系支持**；无法登录时，可在账户页面的**联系我们**取得同一支持邮箱。

<Steps>
  <Step title="写清问题">
    在**问题说明**写明：哪个页面、针对什么对象、做了什么、看到了什么，以及预期结果。补充发生时间、影响范围、可复现步骤和已做的检查。

    软件版本会列入复制内容。设备或部署问题再按需补充型号、序列号、固件版本、当前配置版本及相关回执；这些资料不会自动收集。
  </Step>
  <Step title="选择并检查附带内容">
    **当前对象、日志、截图**均为可选，默认不附带，只选择解决问题所需的内容。请勿填写或发送密码、短信验证码、令牌与密钥；检查文字、图片和附件，移除电子邮箱、手机号码、网址路径及无关个人或客户资料。

    页面不会自动截图，也不保证截图自动脱敏。请在选择和发送前自行检查。
  </Step>
  <Step title="复制后发送邮件">
    点击**复制内容**，将文本粘贴到发给 [support@pacom.cn](mailto:support@pacom.cn) 的邮件中；选择的截图须另外作为邮件附件添加。

    当前支持服务尚未接入，页面不能直接提交或上传截图。**已复制**仅表示内容已复制，不代表已发送或受理；浏览器无法自动复制时，按提示选中下方全文手动复制。发送后保留邮件往来和支持回复，便于跟进。
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="附带内容具体包含什么" description="先预览再决定，页面日志与设备日志分别准备。">
    - **当前对象**：当前机构与角色、页面名称和页面地址；不是自动导出整个项目。
    - **日志**：本次打开页面以来最近最多 20 条提示与错误，时间按中国标准时间记录；可展开**查看将附带的日志**逐条核对，没有日志时不可选。这是页面内存记录，不是设备日志或完整服务端审计。
    - **截图**：点击 **选择截图…**，选取 PNG 或 JPG 图片，核对文件名与大小；不合适时可**移除**，或点击 **更换截图…** 重新选择。图片需另附在邮件中，选择文件不等于上传。
  </Accordion>
</AccordionGroup>
